# R. Anushka Lakmal — Personal Portfolio

A modern, responsive personal portfolio website built with Next.js 16, React 19, Tailwind CSS v4, and Radix UI components.

## 👤 About

I'm **R. Anushka Lakmal**, an undergraduate student pursuing a **Bachelor of Information and Communication Technology (BICT)** degree at the **Uva Wellassa University of Sri Lanka**.

## 🛠️ Tech Stack

- **Framework:** Next.js 16
- **Library:** React 19
- **Styling:** Tailwind CSS v4
- **UI Components:** Radix UI
- **Language:** TypeScript
- **Package Manager:** pnpm

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/AnushkaLakmal07/portfolio.git

# Navigate to the project directory
cd portfolio

# Install dependencies
pnpm install

# Start the development server
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
